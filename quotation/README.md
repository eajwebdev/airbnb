# EAJ quotation

This is a static monthly quotation page. Open `index.html` through a static web server.

Edit the `PRICING` object at the top of `app.js` to update the base, website, or module prices. All prices are PHP per month **per property**. The business landing page and booking website are mutually exclusive; the booking website includes customer accounts. Online payment integration is selectable only with the booking website.

The page restores selections from its URL, so copied links show the same quotation. The Print / Save PDF button uses the browser's print dialog. Changes to these files require a new deployment before they appear on the hosted page.
